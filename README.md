# GitHub Developer Analytics

A full-stack web application that analyzes a GitHub developer's profile and repositories using the GitHub REST API.

## Features

- Search GitHub users
- View developer profile and repositories
- Total repositories, stars, and forks
- Average stars per repository
- Most used programming language
- Programming language distribution
- Repository metrics visualization
- Most starred and most forked repository
- Responsive dashboard
- Error handling

## Tech Stack

**Frontend**
- React
- Vite
- Axios
- Recharts
- CSS

**Backend**
- Node.js
- Express
- Axios
- CORS

**API**
- GitHub REST API
